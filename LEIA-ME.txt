DESIGNLABMOVEIS 1.100.52 — ÍCONE DO APP + BIBLIOTECA GLOBAL

NOVIDADES
1. O PWA instalado passa a usar o nome “DesignLabMoveis” (sem número da versão no nome).
2. O ícone do app foi trocado pela imagem fornecida.
3. Biblioteca agora tem duas áreas:
   - Minha biblioteca: continua local, como antes.
   - Biblioteca global: conteúdo oficial compartilhado com todos os usuários.
4. Administrador, dentro da Biblioteca global:
   - cria pasta global;
   - apaga pasta global;
   - publica o móvel selecionado;
   - apaga modelo publicado.
5. Usuários comuns:
   - enxergam as pastas/modelos globais;
   - podem inserir uma cópia no projeto;
   - não podem alterar nem apagar o conteúdo oficial.

ATENÇÃO — CLOUDFLARE
Esta versão adiciona API nova. Antes de usar a Biblioteca global:
1. Execute cloudflare/4-biblioteca-global.sql no D1.
2. Publique cloudflare/worker-1.100.52.js no Worker.
3. Mantenha os bindings DB e PROJECTS já existentes.

O modelo global completo é salvo no R2 em:
global-library/items/<ID_MODELO>.json

Os metadados de pastas/modelos ficam no D1.

PWA / ANDROID
O manifest agora usa name e short_name = DesignLabMoveis.
Alguns celulares mantêm nome/ícone antigo em cache. Depois de publicar a versão,
se o Android não atualizar o ícone automaticamente, remova o app instalado e
instale novamente a partir do navegador.

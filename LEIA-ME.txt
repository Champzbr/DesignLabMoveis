DESIGNLABMOVEIS 1.100.29 — PROJETOS SEPARADOS POR CONTA + NUVEM

CORREÇÃO PRINCIPAL
Projetos recentes não são mais compartilhados entre contas no mesmo navegador.

Cada projeto agora tem:
ownerUserId

A tela Projetos recentes mostra somente projetos cujo ownerUserId corresponde
à conta logada.

TROCA DE CONTA
Ao trocar a conta:
- projeto aberto da conta anterior é fechado;
- a cena anterior é limpa;
- lista de projetos é recarregada;
- autosave de emergência usa chave separada por usuário.

PROJETOS ANTIGOS
Projetos das versões anteriores não tinham ownerUserId.

Eles NÃO são atribuídos automaticamente.
Aparecem numa seção:
Projetos antigos deste dispositivo

O usuário pode:
- importar um projeto para a conta atual;
- ou importar todos, com confirmação.

Projetos que já pertencem a outra conta nunca aparecem nessa área.

NÚVEM R2
Também foi implementada nesta versão.

Salvamento:
aparelho → Worker autenticado → D1 + R2

D1:
guarda índice, usuário, nome, revisão, tamanho e datas.

R2:
guarda o projeto completo:
users/<USER_ID>/projects/<PROJECT_ID>.json

OUTRO CELULAR/COMPUTADOR
Ao entrar na mesma conta:
- projetos ausentes são baixados;
- versão mais nova vence;
- versão local mais nova é enviada;
- projeto salvo offline fica pendente e sobe depois.

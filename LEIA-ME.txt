DESIGNLABMOVEIS 1.100.21 — NOVA MARCA + BASE ONLINE

Base: 1.100.20 completa.

ALTERAÇÃO PRINCIPAL
O aplicativo passa a se chamar:

  DesignLabMoveis

A nova marca foi aplicada em:
- tela de login;
- tela inicial;
- barra superior do CAD;
- título da aba/navegador;
- PWA / manifest;
- nome mostrado quando o app é instalado;
- mensagens do sistema;
- pacote Aspire / arquivos de instrução;
- gerenciador de modelos;
- tela de Configurações;
- documentação do pacote.

VERSÃO
Nova versão:
  1.100.21

Arquivo versionado:
  designlabmoveis-1.100.21.html

LOGIN ONLINE
Toda a integração da 1.100.20 foi preservada:
- Netlify Identity;
- criar conta;
- confirmação de e-mail;
- login;
- sessão persistente;
- recuperar senha;
- logout;
- modo local para testes;
- helper de JWT para o futuro Cloudflare Worker.

COMPATIBILIDADE IMPORTANTE
Os identificadores INTERNOS antigos foram mantidos propositalmente, por exemplo:
  mini-cad-pro-project

Também foram preservadas as chaves internas de armazenamento local/IndexedDB.

Isso é necessário para:
- abrir projetos salvos nas versões antigas;
- manter autosaves;
- manter preferências;
- não perder bibliotecas e dados existentes.

Ou seja:
A MARCA mudou para DesignLabMoveis, mas o formato interno continua compatível
com o histórico do projeto.

PRÓXIMO TESTE
Suba este pacote no mesmo projeto Netlify em que o Identity já foi ativado.
Depois teste:
1. Criar conta
2. Confirmar o e-mail
3. Entrar
4. Fechar e reabrir para verificar a sessão
5. Sair da conta

Depois disso partimos para:
Cloudflare D1 → R2 → Worker → projetos na nuvem → Premium.
